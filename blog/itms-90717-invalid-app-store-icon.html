Fix ITMS-90717: "Invalid App Store Icon"

Three checks the 1024×1024 marketing icon has to pass. It's usually the second one that catches people.

Jackson · August 2026

ITMS-90717 is specifically about the large 1024×1024 App Store marketing icon in your asset catalog — not any of the smaller in-app icon sizes, which fail differently if they're wrong. There are three things that trigger it, and they're worth checking in this order since the first two are instant to rule out.

1. It's not exactly 1024×1024 pixels

Not "close to," not scaled down from a bigger image at export time — exactly 1024×1024. Check the actual pixel dimensions of the file in your asset catalog's App Icon set, not just what you remember exporting:

sips -g pixelWidth -g pixelHeight YourIcon1024.png

2. It has an alpha channel

This is the one that catches people most often, because the icon can look completely normal — solid background, no visible transparency — and still fail. PNG export from most design tools (Figma, Sketch, Photoshop) includes an alpha channel by default even when every pixel is fully opaque, and Apple's App Store icon specifically rejects any alpha channel at all, not just visible transparency. Strip it explicitly:

sips -s format png --setProperty formatOptions default \
  --out flattened.png YourIcon1024.png
# then confirm it's actually gone:
sips -g hasAlpha flattened.png

If hasAlpha still comes back yes after that, flatten it against a solid background in an image editor and re-export — some tools re-add an alpha channel on save regardless of the export setting.

3. It's missing from the asset catalog, not just the wrong size

Less common, but if you're using an .xcassets App Icon set generated by a tool (a cross-platform framework's icon generator, or an older asset catalog format), it's possible the 1024×1024 marketing slot was never populated at all, even though the app builds and runs fine — the smaller sizes are what iOS actually uses to render the icon on-device, so a missing marketing slot doesn't break anything until you try to submit. Open the App Icon set in Xcode directly and confirm the App Store slot has an image assigned, not just the device-size slots.

If you're generating icons through a cross-platform framework's icon tool (Capacitor, Cordova, Flutter's icon packages), regenerate from a source image that has no transparency at all, rather than trying to fix the exported 1024×1024 after the fact — most of these generators just resize whatever source you gave them, alpha channel included.
