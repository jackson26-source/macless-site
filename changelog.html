What's actually shipped

The reliable way to check for updates is comparing the dates below against when you last downloaded, and re-grabbing the zip from your original purchase confirmation link if anything here looks relevant to you.

2026-08-19

  • Automated certificate/keystore expiry monitoring. A weekly scheduled workflow (also runnable on demand) checks whichever of your iOS profile/cert and Android keystore secrets are set, and pings a webhook only when something's actually expiring or expired — silent the rest of the time. A full report always lands in that run's Summary tab regardless.
  • Signing Doctor now checks Android keystores, not just iOS. Checks whether a keystore opens with the given password/alias, whether the signing key has expired or is expiring soon, and flags an older SHA1-based signature algorithm. Only needs a JDK — no macOS requirement, unlike the iOS checks.
  • The setup wizard now covers Android too, and can push secrets straight to GitHub for you if you have the GitHub CLI installed and logged in, instead of copy-pasting each secret into the web UI by hand. Falls back cleanly to the old copy-paste flow if it isn't. Ends by running Signing Doctor against exactly what it just generated.

2026-08-18

  • Legibility pass on the docs. The setup and signing guides now define their own jargon in plain language the first time it's used — GitHub Actions, Xcode, App Store Connect, TestFlight, certificate, provisioning profile, bundle ID, Team ID — instead of assuming you already know it. No instructions changed, same steps, same order.
  • Store metadata automation added. Pushes your listing text and screenshots to App Store Connect / Play Console via fastlane, reusing the same credentials you already set up for TestFlight/Play Store uploads. Never touches your build, never submits for review. Optional.
  • React Native and Flutter workflow variants are now live-tested and proven, not just reviewed. The React Native live-test found and fixed two real bugs (a dependency pin that doesn't exist before RN 0.85, and a trimmed test scaffold missing a file the bundler needs at archive time) before a clean run succeeded end to end.
  • Macless Signing Doctor released as a free standalone tool — the same signing validation this template runs internally, usable against any provisioning profile/certificate pair, in or out of this pipeline.
  • Bare React Native and Flutter workflow variants added, alongside the existing Capacitor one. Same signing setup and secrets, only the build steps before signing differ.
  • Security hardening pass, prompted by an outside review. Added a .gitignore covering every signing-material file type, so a copy-pasted local command can't accidentally get committed. Added an explicit read-only permissions block to every workflow — none of them need to write back to the repo, so the default token no longer inherits more access than it needs. Audited the full commit history of this template's source and of the real app it's built from for any previously-committed cert or key file — none found. Confirmed secrets were always passed through GitHub Actions secrets, never printed into logs, and never triggered by pull requests from forks.
  • Fixed the Android build workflow after live-testing it end to end on a disposable repo, which caught three real bugs anyone following the guide would have hit — a missing platform dependency, a version-resolution error, and a Java version mismatch. Build and signing are confirmed working; only the final Play Store upload step remains untested against a real Play Console account.

2026-08-17

  • Added a screenshots workflow that generates the exact sizes Apple requires at submission time, by running the Simulator at those device classes.
  • Fixed a real bug in the Simulator-preview workflow where a product lookup could report "not found" even after a fully successful build. Now live-tested end to end.
  • Added the Android build workflow and guide, structured the same way as the iOS pipeline.
  • Added optional build caching for faster repeat runs, and an optional webhook notification step for build success/failure.
  • Added an interactive script that walks through certificate/profile generation and writes the values straight to files, instead of copy-pasting each command by hand.
  • Added a guide for live-testing a workflow change in a throwaway repo before trusting it — the exact process that caught the bug above.

2026-08-16

  • Fixed a critical packaging bug: the product zip was missing the actual pipeline file, even though the setup guide told you to copy it in. If you bought before this date and hit a dead end at that step, re-download from your original purchase confirmation link, it's fixed now.
  • Added a Simulator-preview workflow — build and screenshot your app in the iOS Simulator, no signing setup or Apple hardware required.
  • Added a validation step to the main pipeline that checks your provisioning profile's Team ID and bundle ID against your secrets before the archive step, so a mismatch fails with a specific reason instead of a generic error buried in the log.
